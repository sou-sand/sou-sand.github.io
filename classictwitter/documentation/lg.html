developer unlocking

Follow these steps carefully:

  1. Open the dialer and enter: ##634#
  2. By doing so, the phone should open an app called "MFG". When prompted, input the following password: 277634#*# and press enter.
  3. After doing so, the app should prompt you to choose your menu. Pick Engineer Menu -> Other Settings -> Edit Registry.
  4. Proceed to do the following steps carefully, because if you put even a single character wrong, it can mess up your phone, or just not work at all.
  5. Set ROOT_PATH to: "HKEY_LOCAL_MACHINE".
  6. Set SUB_PATH to: "\Comm\Security\LVMod".
  7. Set KEY to: "DeveloperUnlockState".
  8. Set Data type to: "DWORD".
  9. Tap Query. The output result should return a "0" or a very long random number.
  10. Set Data (not to be confused with data type) to "1" and hit Set. Output result should be ""DeveloperUnlockState" = 1".

preventing the phone to get locked when syncing to zune

Note: We are still not done yet. Your phone might get locked when synced to Zune, so follow these steps to prevent that from happening.
Why is this needed?

Because it prevents the developer unlocked state from going back to 0 (false).

Follow these steps carefully:

  1. Still in the same menu (follow the previous steps if you already left), set KEY to "PortalUrlProd" and set data type to "DWORD".
  2. Tap Query. Output should return data (e.g. "PortalUrlProd" = 77207376).
  3. Keep Data blank, and tap Set. Output result should be ""PortalUrlProd" = 0".
  4. Still in the same menu, set SUB_PATH to "\Software\Microsoft\DeviceReg".
  5. Set KEY to "PortalUrlInt", and set Data type to DWORD.
  6. Tap Query. The output should return data (e.g. "PortalUrlInt" = 0)
  7. Keep DATA blank, and tap Set. The output should be ""PortalUrlInt" = 0"
  8. Hit back until you leave the app and restart your phone.
