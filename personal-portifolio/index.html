WhatsAppForWP
A WhatsApp client that runs on a 2014 phone, written from the protocol up. The phone talks to WhatsApp itself: Noise handshake, binary nodes, the Signal ratchet, media. There is no server to run and nothing to configure.
You can join our server to contribute!
We need coders, artists, translators, etc. (Volunteers) More info at the GitHub repo and Discord server!
